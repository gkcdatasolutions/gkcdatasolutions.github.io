Product

Data Discovery

Data Discovery is a Windows application that turns protected document archives into searchable, cited evidence while leaving original source files unchanged.

Supported content

  • Microsoft Word
  • Microsoft Excel
  • PDF
  • Plain-text .txt
  • Email .eml

Source protection

Original source documents are treated as read-only. Search indexes, generated content and evidence outputs are created separately from the source archive.
